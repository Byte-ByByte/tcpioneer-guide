# Error Codes

Error codes are codes that TCPIOneer emits through [error objects](/guide/return-objects/error) that further explain an error's cause.

## Codes

Below is a table of codes that TCPIOneer can emit.

|Code|Message|
|----|-------|
GENERAL_ERROR|A general error has occurred and a specific issue is not found.
SESSION_NOT_FOUND|The session could not be found.
SESSION_DELETED|The session has been deleted.
FORBIDDEN|The client's action is forbidden by the server.
